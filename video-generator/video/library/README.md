# Vlastní B-roll

Nejvěrohodněji působí záběry, které natočíš sám/sama mobilem. Ulož je do podsložek podle tagů:

```
video/library/
  laptop_night/   notebook v noci, psaní ve tmě
  library/        knihovna, studovna
  phone_scroll/   scrollování na mobilu
  phone_down/     mobil displejem dolů, mobil v šuplíku
  notes/          ruka píše poznámky
  desk/           stůl shora, skripta
  timer/          časovač na mobilu
  …
```

Všechny tagy (a anglické dotazy, podle kterých se hledá na Pexels) jsou v `j5m/content.py → BROLL_TAGS`.
Podporované formáty: mp4, mov, m4v, webm, mkv a obrázky jpg/png/webp. Na orientaci nezáleží – ořízne se na 9:16.
Tahle složka se necommituje do gitu.
