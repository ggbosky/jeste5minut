# Maskot (volitelné)

V referenčním stylu stojí vpravo dole maskot, který mění výraz podle scény. Sem dej **vlastní** postavičku
jako PNG s průhledným pozadím (ideálně 800–1200 px na výšku, postava „vyříznutá“ od pasu nahoru):

| soubor | kdy se použije |
| --- | --- |
| `wave.png` | začátek, výchozí (povinný, pokud máš aspoň jeden) |
| `think.png` | chyby, vysvětlování |
| `surprised.png` | šokující detail |
| `happy.png` | řešení, pochvala |
| `wink.png` | závěr (Sledovat) |

Chybějící nálady nahradí `wave.png`. Když je složka bez PNG, video maskota nemá a karty jsou větší.

Použij jen postavu, ke které máš práva (vlastní ilustrace, zakázka pro ilustrátora, licencovaný asset).
Maskota jiné značky (např. lišku z videí Project Two) nepoužívej – je to jejich poznávací znak.
